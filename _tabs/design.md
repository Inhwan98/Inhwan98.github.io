> 기준 문서는 게임 저장소의 `SCRATCH_GUILD_GDD.md`(2026-11-13, 초안)입니다. 이 페이지는 그 요약이며, 확정된 것과 제안을 구분해 적습니다.

## 한 줄 소개

**동전으로 복권을 긁어 용병단을 싸우게 하는 턴제 로그라이크.**

- **운:** 복권 칸 아래에 무엇이 있는지는 모릅니다.
- **판단:** 어느 칸을, 어떤 순서로, 몇 칸까지 긁을지 정합니다.
- **손맛:** 마우스로 문질러 긁고, 은박 가루가 날리고, 숫자가 하나씩 터집니다.

## 왜 즉석 복권인가

- Steam에서 긁기를 중심에 둔 게임은 대부분 방치형입니다. 긁기를 **전투 · 퍼즐 로그라이크**로 만든 게임은 조사 범위에서 리뷰 100개를 넘긴 사례가 없었습니다.
- 한국 즉석 복권의 판정 방식(같은 금액 3개, 행운숫자 일치, 그림 짝 맞추기)은 그대로 퍼즐 규칙으로 옮기기 쉽습니다.
- 긁기 게임 리뷰에서 배운 점: 클릭보다 **드래그로 문지르는 손맛**이 첫 번째 셀링 포인트이고, 긁을 때마다 판단이 있어야 반복 노동이 되지 않습니다.

## 핵심 루프

```
[거점] 용병단 정비 · 해금 · 의뢰 선택
   ↓
[런: 의뢰 1회, 30~45분]
  지도에서 노드 선택 → 전투(전투 복권을 긁어 싸움) → 보상 복권 1장 골라 긁기
        → 복권방(상점) · 이벤트 · 휴식 → … → 층 보스 → 다음 층
   ↓
[귀환] 런 결과 정산 · 해금 · 부상과 피로 반영
```

## 전투 규칙 (확정된 뼈대)

- **용병 1명 = 복권 1장.** 출전한 용병마다 그 용병의 행동이 인쇄된 복권이 매 턴 나옵니다.
- **동전 내구도**로 한 턴에 긁을 수 있는 칸 수를 제한합니다. 모든 칸을 다 긁을 수는 없습니다.
- 복권 종류마다 판정이 다릅니다: 3매치형, 행운형, 짝형, 줄형, 배수 칸.
- 적은 주사위를 굴리지 않습니다. 다음 행동과 피해량을 미리 보여 주고, 랜덤은 복권 내용 한 층에만 둡니다.

### 한 턴의 판단

1. 적 예고 확인
2. 동전 내구도 안에서 어느 복권의 어느 칸을 긁을지 고르기
3. 더 긁을지, 다음 턴을 위해 동전을 아낄지 정하기
4. 도구 사용 (돋보기, 지우개, 덧칠)
5. 턴 종료: 드러난 칸이 순서대로 발동하고 적이 예고한 행동을 합니다

## 투명성 원칙

- 각 복권에 어떤 행동이 몇 칸 남아 있는지 언제든 볼 수 있습니다.
- 상점에서 파는 복권은 등위별 확률을 표시합니다. 숨은 보정은 없습니다.
- 적 예고 · 남은 칸 정보 · 확률 표시는 어떤 난이도에서도 빼앗지 않습니다.
- "아깝다"는 긴장은 연출로 살리되, 결과를 일부러 근접 실패로 만드는 장치는 넣지 않습니다. 실제 돈 · 현금화는 없습니다.

## 보상 복권

| 복권 | 나오는 것 |
| --- | --- |
| 용병 복권 | 새 용병 (들어온 용병은 자기 전투 복권을 가져옴) |
| 금화 복권 | 금화, 다음 복권 할인권 |
| 행운 복권 | 부적: 규칙을 바꾸는 영구 효과 |
| 인쇄 복권 | 특정 용병 복권의 칸 하나를 영구 변경 |
| 동전 복권 | 동전 강화 |
| 저주 복권 | 꽝 칸이 섞였지만 당첨금이 큼 |

## 세계관

레트로 판타지 혼합. 용병 계약을 **길드 복권**으로 정산하는 도시입니다. 1등이 여러 번 나온 "명당 여관", 남은 1등 게시판처럼 한국 복권 문화가 판타지 장소에 섞입니다.

## UI 방향 (제안)

정보는 평면적이고 정확하게, 복권만 실물처럼. 현대적 HUD를 뼈대로 하고 일련번호 · 절취선 · 상금표 · 고무도장 같은 인쇄물 요소를 섞습니다.
