## 한 일

- Unity CLI가 에디터와 통신하도록 Pipeline 패키지를 설치하고, CLI를 최신 버전으로 업데이트
- 에디터에 C# 코드를 보내 결과가 돌아오는 것까지 확인
- 작업 트래커 · 개발 일지 · 기획 요약을 담은 이 개발 기록 사이트를 만듦
- 처음에는 직접 만든 Notion 풍 화면으로 공개했고, 같은 날 블로그 테마 Chirpy로 옮김. 작업 트래커(보드 · 백로그 · 로드맵 · 에픽)는 탭 하나로 옮겨 그대로 유지

## 사이트를 이렇게 만든 이유

- 유지비가 들지 않아야 했습니다. GitHub Pages의 정적 사이트라 서버 · 도메인 비용이 없습니다. 빌드는 공개 저장소에서 무료인 GitHub Actions가 합니다.
- 글과 작업 목록은 Markdown · JSON 파일이라, 저장소에 커밋하는 사람(저)만 고칠 수 있고 방문자는 읽기만 합니다.
- 블로그 테마로 옮기면서 카테고리 · 태그 · 보관함 · 검색 · 글 목차를 따로 만들지 않고 얻었습니다.
